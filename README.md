# ربات آغازگر گفت‌وگوی گیم کنسولی

یک worker پایتون برای گروه تلگرام که پس از ۱۵ دقیقه بی‌پیامی یک پرسش گیمی می‌فرستد و به منشن/ریپلای‌ها و پیام‌های مربوط به بازی‌های کنسولی پاسخ می‌دهد. تولید پاسخ با API سازگار با OpenAI در CoArena انجام می‌شود.

## تنظیمات پیش‌فرض

- سکوت لازم برای آغاز بحث: ۱۵ دقیقه؛ فاصلهٔ حداقلی بین دو بحث خودکار: ۶۰ دقیقه.
- پاسخ‌گویی به منشن یا ریپلای به ربات و نیز پیام‌های کنسولی مرتبط؛ ریپلای و منشن مستقیم از محدودیت نرخ عبور می‌کند.
- پاسخ‌های خودکارِ غیرمستقیم حداکثر یک‌بار در هر ۶۰ ثانیه فرستاده می‌شوند.
- لحن پاسخ‌ها دوستانه و کمی صمیمی، در عین حال محترمانه و جدی است؛ ربات از ایموجی و شکلک استفاده نمی‌کند و سؤال‌های شروع گفت‌وگو را نیز با همین لحن می‌سازد.
- مدل پیش‌فرض `deepseek-v4-1-flash-1017` است و با `COARENA_MODEL` قابل تغییر است.
- برای پرسش‌های خبر/آپدیت/تاریخ انتشار/قیمت تازه، ربات Google News RSS را جست‌وجو می‌کند و در صورت نیافتن نتیجهٔ دقیق، عبارت‌های عمومی‌تر را نیز امتحان می‌کند. برای این RSS کلید جداگانه‌ای لازم نیست.
- گروه پیش‌فرض `@Pixel_Mediair` است.

## تنظیم API در CoArena

1. در [صفحهٔ API CoArena](https://coarena.ai/account/api) یک API key بساز. طبق مستند فعلی، ساخت کلید رایگان است.
2. در Railway مقدار کلید را با نام `COARENA_API_KEY` به‌صورت Variable محرمانه ثبت کن. کلید را در چت، کد، فایل عمومی یا GitHub قرار نده.
3. endpoint پیش‌فرض پروژه `https://coarena.ai/api/v1` است. اگر لازم شد می‌توان آن را با `COARENA_BASE_URL` تغییر داد.
4. مدل پیش‌فرض `deepseek-v4-1-flash-1017` است؛ اگر در حساب تو در دسترس نبود، مقدار `COARENA_MODEL` را به یکی از شناسه‌های فعال در [مستند مدل‌های CoArena](https://coarena.ai/docs) تغییر بده.

CoArena سازگاری OpenAI را مستند کرده و نمونهٔ درخواست را روی `/api/v1/chat/completions` با `Authorization: Bearer` نشان می‌دهد. صفحهٔ مستندات فعلی سهمیهٔ رایگان روزانهٔ ۵ دلارِ مصرف مدل، ۳۰ درخواست در دقیقه و حداکثر ۲ درخواست هم‌زمان را ذکر می‌کند؛ سقف‌های حساب ممکن است جداگانه اعمال شوند. اگر پاسخ HTTP 429 دیدی، محدودیت روزانه یا نرخ حساب را در صفحهٔ API بررسی کن.

## استقرار روی Railway

اگر repository از قبل به Railway وصل است، پس از دریافت commit جدید یک redeploy انجام بده. در تب **Variables** این مقادیر را ثبت یا به‌روز کن:

- `TELEGRAM_BOT_TOKEN`: توکن BotFather
- `COARENA_API_KEY`: کلید ساخته‌شده در CoArena
- `COARENA_BASE_URL`: اختیاری؛ پیش‌فرض `https://coarena.ai/api/v1`
- `COARENA_MODEL`: اختیاری؛ پیش‌فرض `deepseek-v4-1-flash-1017`
- `TARGET_CHAT_USERNAME`: `Pixel_Mediair`
- `IDLE_MINUTES`: `15`
- `TOPIC_COOLDOWN_MINUTES`: `60`
- `REPLY_COOLDOWN_SECONDS`: `60`
- `NEWS_SEARCH_ENABLED`: `true`
- `NEWS_SEARCH_MAX_RESULTS`: `4`
- `TARGET_CHAT_ID`: اختیاری؛ شناسهٔ عددی برای گروه خصوصی یا گروهی که username آن match نمی‌شود.

اگر قبلاً متغیرهای `FREEMODEL_API_KEY`, `FREEMODEL_BASE_URL` یا `FREEMODEL_MODEL` در Railway داری، آن‌ها را حذف کن یا دیگر به آن‌ها تکیه نکن؛ نسخهٔ جدید از متغیرهای `COARENA_*` استفاده می‌کند. Start Command همان `python bot.py` باقی می‌ماند. این سرویس worker polling است و به دامنه یا پورت HTTP نیاز ندارد.

در Deploy Logs باید پیام شروع ربات و مدل CoArena دیده شود. در گروه `/status` را بفرست تا وضعیت را بررسی کنی.

برای اجرای محلی، `requirements.txt` را نصب کن، `.env.example` را به `.env` کپی و مقادیر را کامل کن، سپس `python bot.py` را اجرا کن. فایل `.env` در `.gitignore` است.

## پیش‌نیازهای تلگرام

1. با `@BotFather` توکن بساز و آن را فقط در متغیر امن Railway قرار بده.
2. در `@BotFather` دستور `/setprivacy` را اجرا و Privacy Mode را خاموش کن تا ربات پیام‌های گروه و سکوت را تشخیص دهد. برای این کاربرد لازم نیست ادمین باشد.
3. ربات را به گروه `Pixel_Mediair` اضافه کن. اگر لازم است شناسهٔ عددی گروه را به‌عنوان `TARGET_CHAT_ID` ثبت کن.

## حریم خصوصی و عیب‌یابی

ربات متن گروه را برای تشخیص سکوت ذخیره نمی‌کند؛ فقط زمان آخرین فعالیت را در حافظهٔ موقت نگه می‌دارد. پیام‌های دارای منشن/ریپلای یا پیام‌هایی که فیلتر محلی مرتبط با کنسول تشخیص می‌دهد، به CoArena فرستاده می‌شوند. پرسش‌های خبری برای جست‌وجوی RSS هم استفاده می‌شوند. تاریخچهٔ گروه در فایل یا پایگاه داده ذخیره نمی‌شود.

- اگر ربات پیام گروه را نمی‌بیند، Privacy Mode و `TARGET_CHAT_USERNAME` یا `TARGET_CHAT_ID` را بررسی کن.
- اگر پاسخ API خطا دارد، Railway Logs را ببین، مطمئن شو `COARENA_API_KEY` درست تنظیم شده و `COARENA_MODEL` در دسترس است. کلید API را در لاگ یا پیام نفرست.
- برای خطای 429، احتمالاً به سقف روزانه/درخواست رسیده‌ای یا محدودیت حساب فعال شده است.
- اگر خبر روز پیدا نمی‌شود، در Logs دنبال `Live gaming-news search` بگرد؛ خطاهای اتصال RSS مستقل از CoArena هستند.
- فقط یک deployment فعال را با همان Bot Token اجرا کن؛ چند polling هم‌زمان می‌تواند باعث تداخل دریافت پیام شود.

پس از restart، زمان آخرین فعالیت و تاریخچهٔ موقت بحث‌ها از حافظه پاک می‌شود و زمان سکوت از اولین پیام بعدی شروع خواهد شد.
