# ربات آغازگر گفت‌وگوی گیم کنسولی

یک worker پایتون برای گروه تلگرام که پس از ۱۵ دقیقه بی‌پیامی یک پرسش گیمی می‌فرستد و به منشن/ریپلای‌ها و پیام‌های مربوط به بازی‌های کنسولی پاسخ می‌دهد. متن تولیدشده با API سازگار با OpenAI در FreeModel ساخته می‌شود.

## تنظیمات پیش‌فرض

- سکوت لازم برای آغاز بحث: ۱۵ دقیقه.
- فاصلهٔ حداقلی بین دو بحث خودکار: ۶۰ دقیقه.
- پاسخ‌گویی: به منشن یا ریپلای به ربات؛ همچنین به پیام‌هایی که پیش‌فیلتر محلی آن‌ها را مرتبط با بازی‌های کنسولی تشخیص دهد.
- سقف پاسخ: حداکثر یک پاسخ در هر ۶۰ ثانیه در گروه، برای جلوگیری از شلوغی و هزینهٔ ناخواسته. مقدارش با `REPLY_COOLDOWN_SECONDS` قابل تغییر است.
- گروه پیش‌فرض: `@Pixel_Mediair`.
- اگر `FREEMODEL_MODEL` را خالی بگذاری، برنامه مدل چتِ در دسترس را از فهرست FreeModel انتخاب می‌کند که کمترین قیمت اعلام‌شدهٔ ورودی و خروجی را دارد. برای انتخاب دستی، شناسهٔ مدل را در همان متغیر بگذار.

## پیش‌نیازهای تلگرام

1. در تلگرام با `@BotFather` دستور `/newbot` را اجرا کن و توکن ربات را دریافت کن. توکن را در چت، کد یا GitHub قرار نده.
2. در `@BotFather` دستور `/setprivacy` را بزن، رباتت را انتخاب کن و Privacy Mode را خاموش کن. این کار لازم است تا ربات بتواند تشخیص دهد گروه ساکت شده است. ربات را ادمین نکن؛ برای این کاربرد دسترسی ادمین لازم نیست.
3. ربات را به گروه `Pixel_Mediair` اضافه کن. اگر گروه با نام کاربری عمومی قابل دسترسی نیست، در گروه دستور `/id` را بزن و مقدار شناسه را برای `TARGET_CHAT_ID` استفاده کن.

## راه‌اندازی API

در [داشبورد FreeModel](https://freemodel.in/dashboard) یک API key بساز. این پروژه از `https://freemodel.in/v1/chat/completions` و احراز هویت Bearer استفاده می‌کند. کلید را فقط در متغیر محرمانهٔ Railway قرار بده.

## استقرار روی Railway

1. محتویات این پوشه را در یک repository خصوصی GitHub قرار بده؛ فایل `.env` واقعی را هرگز commit نکن.
2. در Railway یک پروژه بساز و repository را از مسیر **Deploy from GitHub Repo** متصل کن.
3. در تنظیمات سرویس، **Start Command** را روی `python bot.py` بگذار. این سرویس یک worker polling است و به دامنه یا پورت HTTP نیاز ندارد.
4. در تب **Variables** سرویس، این مقادیر را اضافه کن:

   - `TELEGRAM_BOT_TOKEN`: توکن BotFather
   - `FREEMODEL_API_KEY`: کلید API فری‌مدل
   - `TARGET_CHAT_USERNAME`: `Pixel_Mediair`
   - `IDLE_MINUTES`: `15`
   - `TOPIC_COOLDOWN_MINUTES`: `60`
   - `REPLY_COOLDOWN_SECONDS`: `60`
   - `FREEMODEL_MODEL`: اختیاری؛ در صورت خالی‌بودن، برنامه ارزان‌ترین مدل چتِ دارای قیمت در فهرست API را انتخاب می‌کند.
   - `TARGET_CHAT_ID`: اختیاری؛ برای گروه خصوصی یا وقتی username match نمی‌شود. اگر این متغیر تنظیم شود، شناسهٔ عددی آن مبنای فیلتر گروه است.

5. Deploy را اجرا کن و در Railway از **Deploy Logs** مطمئن شو پیام شروع ربات و مدل انتخاب‌شده ثبت شده است. در گروه `/status` را بفرست تا تنظیمات اجرا را ببینی.

برای اجرای محلی، `requirements.txt` را نصب کن، `.env.example` را به `.env` کپی و مقادیر را کامل کن، سپس `python bot.py` را اجرا کن. فایل `.env` در `.gitignore` است.

## حریم خصوصی و هزینه

برای تشخیص سکوت، ربات متن پیام‌ها را ذخیره نمی‌کند و فقط زمان آخرین پیام را در حافظهٔ موقت نگه می‌دارد. برای پاسخ‌گویی، فقط پیام‌های دارای منشن/ریپلای یا پیام‌هایی که پیش‌فیلتر محلی نشانه‌های گیم کنسولی را در آن‌ها پیدا کند، به FreeModel فرستاده می‌شوند؛ متن‌های دیگر برای مدل ارسال نمی‌شوند. پرسش‌های آغازگر خودکار نیز با مدل تولید می‌شوند. مدل انتخابی، تعرفه و سهمیهٔ API به حساب FreeModel تو بستگی دارد؛ پیش از استفاده، قیمت مدل را در داشبورد/فهرست مدل‌ها بررسی کن.

بعد از restart سرویس، وضعیت زمان آخرین فعالیت از حافظه پاک می‌شود و شمارش سکوت از اولین پیام بعدی شروع می‌شود. متن پیام‌ها و تاریخچهٔ گروه در فایل یا پایگاه داده ذخیره نمی‌شود.

## عیب‌یابی

- **ربات پیام گروه را نمی‌بیند:** Privacy Mode را در BotFather خاموش کن، ربات را بعد از تغییر تنظیم به گروه اضافه/حذف‌و‌اضافه کن و بررسی کن متغیر `TARGET_CHAT_USERNAME` یا `TARGET_CHAT_ID` به گروه درست اشاره کند.
- **گروه عمومی نیست:** دستور `/id` را بزن و `TARGET_CHAT_ID` را در Railway تنظیم کن.
- **خطای مدل یا API:** در Logs خطاهای FreeModel را بررسی کن، کلید را در Railway دوباره تنظیم کن و در صورت نیاز شناسهٔ یک مدل فعال را در `FREEMODEL_MODEL` قرار بده.
- **دو نمونهٔ هم‌زمان پیام می‌دهند:** مطمئن شو فقط یک deployment فعال از این ربات با همین Bot Token وجود دارد؛ polling تلگرام برای یک توکن نباید هم‌زمان در چند نمونه اجرا شود.
